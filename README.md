# Atividade de Versionamento

Repositório de exercício para praticar Git e observar alterações em arquivos de texto.

## Arquivos

- [index.txt](index.txt): exemplo HTML com o conflito resolvido.
- [main.txt](main.txt): registro de criação de arquivo no repositório.

## Sobre o conflito

O conflito original foi preservado em [exemplos/conflito-nao-resolvido.txt](exemplos/conflito-nao-resolvido.txt). Compare as duas versões com o `index.txt` para estudar como conciliar mudanças concorrentes.

## Contexto

Material de aprendizagem de controle de versão. Este repositório não é uma aplicação pronta para uso.
