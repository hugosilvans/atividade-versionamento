# Atividade de Versionamento

Repositório de exercício para praticar Git e observar alterações em arquivos de texto.

## Arquivos

- [index.txt](index.txt): conteúdo HTML em arquivo de texto, com marcadores de conflito de merge.
- [main.txt](main.txt): registro de criação de arquivo no repositório.

## Sobre o conflito

O `index.txt` contém os marcadores `<<<<<<< HEAD`, `=======` e `>>>>>>> feature1`. Eles registram um conflito ainda não resolvido entre duas versões de um título. Foram preservados como parte do estado do exercício.

## Contexto

Material de aprendizagem de controle de versão. Este repositório não é uma aplicação pronta para uso.
